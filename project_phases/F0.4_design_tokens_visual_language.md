# F0.4 — Design Tokens & Visual Language: Implementation Plan

> Phase 0 — Foundations. Source: `project_plan.md`.

---

## Context
F0.3 delivered the page shell using hardcoded Tailwind `zinc-*` values throughout. F0.4 establishes a real design token system: a named palette, a type scale, and spacing/radius tokens — all defined as CSS custom properties in `globals.css` so a designer can update the whole look by editing one block. Components are then updated to reference these tokens instead of raw Tailwind color names.

The aesthetic target is "Google Maps × The Sims" — playful and colorful but not gamified. The site chrome (header, footer, section backgrounds) carries the palette; the map and interactive sections stand out through higher contrast and saturation. Primary color is not blue. Dark mode is preserved.

A separate `docs/style-guide.md` is created as a living reference for designers.

---

## Decisions
- **Primary color**: Warm sage green — map-like, not blue, not loud
- **Accent**: Warm amber/yellow — CTAs and interactive highlights
- **Backgrounds**: Light primary tints for sections; map section uses a dark green for high contrast
- **Token system**: All values as CSS custom properties in `@theme inline` in `globals.css` — single source of truth, maximally editable
- **Font**: Geist Sans (already loaded) — no new fonts added
- **Dark mode**: Preserved via `@media (prefers-color-scheme: dark)` overrides on the same token names

## Token System

All tokens live in the `@theme inline` block in `src/app/globals.css`.

### Color tokens
```css
/* Brand */
--color-primary:        #5C8B5A;   /* sage green */
--color-primary-light:  #EDF4EC;   /* very light green wash — section backgrounds */
--color-primary-dark:   #3A5C39;   /* deeper green — header, footer, hover states */
--color-accent:         #E8A838;   /* warm amber — CTAs, highlights */
--color-accent-light:   #FDF3DC;   /* light amber wash */

/* Surface */
--color-surface:        #FAFAF7;   /* warm off-white — page background */
--color-surface-muted:  #F0F0EA;   /* slightly darker — alternating sections */
--color-map-bg:         #2C3E2D;   /* dark green — map section, high contrast */

/* Text */
--color-text:           #1C2B1C;   /* near-black with green tint */
--color-text-muted:     #5A6B5A;   /* muted body text */
--color-text-on-dark:   #F0F4EF;   /* text on dark backgrounds */

/* Border */
--color-border:         #D4DDD3;   /* subtle green-tinted border */
--color-border-strong:  #8FAD8E;   /* stronger border for emphasis */
```

### Typography tokens
```css
--font-sans: var(--font-geist-sans), system-ui, sans-serif;
--font-mono: var(--font-geist-mono), monospace;
```
Type scale uses Tailwind's built-in `text-xs` through `text-4xl` — no custom overrides needed.

### Border radius tokens
```css
--radius-sm:  0.25rem;
--radius-md:  0.5rem;
--radius-lg:  0.75rem;
--radius-xl:  1rem;
```

## Implementation Steps

### Step 1 — Expand `globals.css`
Replace the minimal existing `@theme inline` block with the full token set above. Add dark mode overrides inside `@media (prefers-color-scheme: dark)` on `:root`. Update the `body` base style to use `bg-surface text-text`.

Dark mode overrides:
- `--color-surface` → `#0F1A0F`
- `--color-surface-muted` → `#1A2B1A`
- `--color-text` → `#E8F0E8`
- `--color-text-muted` → `#9AB09A`
- `--color-border` → `#2E422E`

### Step 2 — Update `Header`
| Property | Token class |
|---|---|
| Background | `bg-primary-dark` |
| Title text | `text-text-on-dark` |
| Nav links | `text-text-on-dark/80 hover:text-text-on-dark` |
| Border bottom | `border-primary-dark` |

### Step 3 — Update section components
| Section | Background | Placeholder fill |
|---|---|---|
| `IntroSection` | `bg-surface` | `bg-primary-light border-border` |
| `MapSection` | `bg-map-bg` | `bg-map-bg/50 border-border-strong` (text `text-text-on-dark`) |
| `VideosSection` | `bg-surface-muted` | `bg-surface border-border` |
| `ContactSection` | `bg-primary-light` | `bg-surface border-border` |

### Step 4 — Update `Footer`
| Property | Token class |
|---|---|
| Background | `bg-primary-dark` |
| Text | `text-text-on-dark/70` |
| Border top | `border-primary-dark` |

### Step 5 — Create `docs/style-guide.md`
Document: color palette table (token → hex → usage), section color map, border radius scale, typography notes, and a short "How to update the palette" section for designers.
