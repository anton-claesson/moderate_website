# F0.3 — Base Layout & Responsive Shell: Implementation Plan

> Phase 0 — Foundations. Source: `project_plan.md`.

---

## Context
F0.1 and F0.2 delivered the project scaffold and CI/CD pipeline. `app/page.tsx` still contains the Next.js boilerplate. F0.3 replaces it with the real single-page shell: six semantic sections stubbed out with placeholder content, wired together with a mobile-first responsive layout.

No real content is introduced here (copy, map, videos, form logic all belong to later phases). The goal is a structural scaffold that later features slot into cleanly.

---

## Branch
`feature/base-layout-responsive-shell`

---

## Implementation Steps

### Step 1 — Update `app/layout.tsx` metadata
Change the page title from "Create Next App" to "Stockholm Housing Stock Visualizer" and add a meaningful description. Keep the existing Geist font setup and body/html class structure unchanged.

### Step 2 — Create `Header` component
**File: `src/components/Header.tsx`**

- Sticky top bar
- Left side: project title text (no logo asset yet)
- Right side: anchor nav links → `#intro`, `#map`, `#videos`, `#contact`
- Mobile (default): hide nav links, show title only
- Desktop (`md:` breakpoint): show nav links inline
- No JS hamburger toggle — nav links are sufficient for F0.3; interactive mobile nav can come in Phase 1
- Tailwind only; no new dependencies

### Step 3 — Create stub section components
Each section gets its own file under `src/components/sections/`. All sections receive an `id` prop for anchor navigation and render a clearly labeled placeholder block so the page has real scroll depth.

**`src/components/sections/IntroSection.tsx`**
Placeholder text area. `min-h-[50vh]`. Will hold project description copy in F1.2.

**`src/components/sections/MapSection.tsx`**
Large placeholder div. `min-h-[80vh]`. Background color to visually distinguish it. Will hold the Mapbox GL JS instance in F2.1.

**`src/components/sections/VideosSection.tsx`**
Placeholder grid layout. `min-h-[50vh]`. Will hold embedded videos in F1.3.

**`src/components/sections/ContactSection.tsx`**
Placeholder form area. `min-h-[50vh]`. Will hold the newsletter form in F5.1.

### Step 4 — Create `Footer` component
**File: `src/components/Footer.tsx`**

- Single row: © {year}, "Data: Lantmäteriet / SCB", placeholder contact email
- Full-width, muted background color
- No interactivity

### Step 5 — Rewrite `app/page.tsx`
Replace the boilerplate entirely. Compose the shell:

```tsx
<Header />
<main>
  <IntroSection id="intro" />
  <MapSection id="map" />
  <VideosSection id="videos" />
  <ContactSection id="contact" />
</main>
<Footer />
```

Sections control their own width/padding; no wrapping `container` on `<main>`.

## Constraints
- **Tailwind 4 only** — no new CSS files, no third-party UI component libraries
- **No JS interactions** beyond anchor navigation (no hamburger toggle, no scroll animations)
- **No real content** — all sections are visually labeled stubs
- **Strict TypeScript** — all props typed; no `any`
- **Mobile-first** — design for 375px, scale up with `sm:` / `md:` / `lg:`
